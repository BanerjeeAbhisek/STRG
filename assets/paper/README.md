Operation: render/crop the original PDF region at 300 dpi using Poppler.
Colors, labels, model outputs, map polygons, plots, and data marks remain intact.
The extraction script excludes the stray caption edge for Figure 3 and the
surrounding paper header/caption for Figure 4. No data were digitized or invented
to reconstruct these figures. The repeated Helene image supports the opening
question and later walkthrough of the same published example.

The original paper credits Google; these are attributed reproductions for this
academic paper discussion, not newly created university or author artwork.
